# search_analysis

We are using Python to analyze Google search data focusing on search queries using Trendspy API. It is a maintained Python library for accessing Google Trends data, serving as the primary alternative to the archived pytrends library . With Trendspy you can explore trends, compare search interest from different places and understand what people are searching for in a better way.

**Libraries Used:**
1. Pandas
2. Time
3. Matplotlib
4. Trendpy
5. Plotly
6. Sci-kit Learn
